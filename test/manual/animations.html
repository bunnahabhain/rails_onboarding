rails_onboarding — animation harness

Loads the gem's real stylesheets from app/assets. Every box has a centre crosshair: a correct animation spins or pulses in place, centred on the cross. Serve over HTTP from the repo root (python3 -m http.server 8899) — not file://.

1. Automated check — do all 23 keyframes resolve?

Reads the @keyframes rules straight out of the loaded stylesheets (recursing into @media blocks) and compares them against the expected list. Catches the three ways the prefixing pass could have gone wrong: a name renamed at the reference but not the definition, a name left unprefixed, and two files defining the same name — the last of which is the spin bug 0.4.1 fixed.
